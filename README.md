## 🛠️ Tecnologías Utilizadas
- **Frontend:** Angular 17+ con Angular Material para una interfaz moderna y responsiva.
- **Backend:** FastAPI (Python) para una API REST robusta y rápida.
- **Gestión de Versiones:** GitFlow (ramas dev, qa, prod, main).

## 🚀 Estructura del Repositorio
- **Rama `main`:** Documentación general del proyecto.
- **Rama `prod`:** Código fuente de la versión estable y final.
- **Rama `dev`:** Historial de desarrollo y commits de funcionalidades.

## 📝 Instrucciones Rápidas
1. Clonar el repositorio.
2. Cambiar a la rama `prod`: `git checkout prod`.
3. Instalar dependencias del frontend: `npm install`.
4. Ejecutar el servidor: `npm start`.
